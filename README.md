This repository serves as my personal learning journal and portfolio for the **Core Data Science Curriculum** offered by UC Berkeley. It contains my notes, lab assignments, homework, and projects as I self-study these rigorous courses.

My goal is to build a strong foundation in statistical inference, data manipulation, machine learning, and data engineering.
